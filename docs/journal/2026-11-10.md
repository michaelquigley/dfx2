## Synthetic mixer stage 4

Implemented on `27e0c4e`, uncommitted; record in `evidence/synthetic-mixer/stage-4.md`. Linux native matrix passes; Windows has executed nothing (handoff in `evidence/synthetic-mixer/windows/stage-4/`). Terminus pending.

- **Pending values are keyed by sequence number, and that is load-bearing.** `resolveLocked` clears a pending value only if its sequence still matches; clearing on any resolution makes an earlier acknowledgment flash a superseded value (fault-injected: caught). `Submit` sets the pending value and writes `accepted` under the queue lock *before* enqueueing; reorder those and the worker can resolve a command whose pending value is not yet set, leaving it pending forever.
- `Submit`'s capacity check `len(q.queue) == cap(q.queue)` is race-free only because every send happens under `q.mu`; the worker only receives. Don't add a sender outside the lock.
- The worker's gate returns `ctx.Err()` even when the delay has elapsed, so a command whose delay ends during shutdown is canceled, not applied. Don't "simplify" the timer branch to `return nil`.
- **Text eviction needs headroom above the steady working set.** An entry the last frame used is never evicted, so a budget below what a window draws every frame evicts nothing and serves the excess transiently each frame. That is the designed behavior, not a bug. The churn label is split into twelve-word lines for the same reason: one oversized paragraph is never admitted, so it never becomes evictable. The small audition budget has to sit between a fresh window's glyph set and everything the churn alphabet can produce (about 50 KB and 215 KB at scale 2, about a quarter at scale 1), hence 48 KiB × scale².
- The Linux controls driver was extended in place; stage 3's retained runs used its `27e0c4e` version. The Windows stage 3 driver was left untouched and copied to `stage-4/controlsdrive`, because its README describes that exact runner.
- The Linux foundation lifetime matrix had not run since 2026-11-04; stage 4's matrix reruns it nested, on Wayland and XWayland.
- Every drag frame is one command, so a long drag at a long delay fills the 64-slot queue and later positions are refused, visibly. The spec forbids coalescing; don't add it to make the manual audition look calmer.

# dfx2

**Desktop apps in Go. Hold the C.**

dfx2 is a Go framework for desktop applications. It draws native user
interfaces itself, with an immediate-mode API, and shows web interfaces in
the system webview, all without cgo. It is the successor to
[dfx](https://github.com/michaelquigley/dfx) (immediate-mode UI on Dear
ImGui) and [dfw](https://github.com/michaelquigley/dfw) (native windows for
Go HTTP apps), and builds on [df](https://github.com/michaelquigley/df).
